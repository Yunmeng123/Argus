# Argus v0.1.0

Argus's first public release packages the existing self-hosted AI review workflow into a reproducible distribution.

## Highlights

- Review pasted unified diffs, local repositories, or GitHub/GitLab/Gitee pull requests.
- Finder–Verifier review, changed-line validation, Java method context, quality scoring, and Markdown reports.
- Web dashboard, developer profiles, runtime configuration, MCP server, and webhook notifications.
- One-command Docker Compose startup with a persistent RabbitMQ queue, H2 data, and reports.
- A no-key mock mode for evaluating the complete UI workflow.
- Public, machine-readable evaluation output with a documented methodology.

## Quick start

```bash
docker compose up --build -d
```

Open <http://localhost:18080>. Mock mode is enabled by default in Compose; set `ARGUS_LLM_MOCK=false` and provide model credentials for real reviews.

## Verification

```bash
mvn test
cd web && npm ci && npm run build
docker compose config
```

## Known limitations

- The bundled evaluation dataset is intentionally small and is suitable only for smoke/regression testing.
- Gitee currently receives summary comments rather than line-level comments.
- Production deployments should replace the default RabbitMQ credentials and set `ARGUS_ACCESS_TOKEN`.
